# Job Extractor

Aplicación web para buscar, extraer y gestionar ofertas de empleo desde diferentes plataformas, con filtros por cargo, ubicación, modalidad y experiencia.

## Tecnologías

* Angular 21
* TypeScript
* Angular Material
* Tailwind CSS
* Node.js + Express
* Cheerio

---

## Funcionalidades

* Búsqueda de ofertas de empleo.
* Integración con LinkedIn, Computrabajo y El Empleo.
* Filtros por ubicación, modalidad y experiencia.
* Ordenamiento y búsqueda dentro de los resultados.
* Guardado de ofertas favoritas.
* Estadísticas de las ofertas encontradas.
* Visualización detallada de cada vacante.
